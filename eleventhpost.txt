☕ Gyaan Ki Baat: Why Docker Boots in 200ms (And VMs Take 45s) 🐳⚡
A VM takes 45 seconds to boot and burns 4GB RAM just idling.
A Docker container boots in 200ms with near-zero idle overhead. 🖥️
Containers are NOT mini virtual machines, they are normal Linux processes with invisible walls!

The 3 Linux superpowers behind Docker:
👀 1. Namespaces (Isolation): Isolates what the process can SEE (PID, network interface, filesystem mounts).
🛑 2. Control Groups / cgroups (Resource Limits): Limits what the process can USE (caps CPU and RAM).
🗂️ 3. OverlayFS (Storage Sharing): Images share read-only layers. Containers only add a tiny writable layer on top!

💡 TL;DR: `docker run` doesn't boot an OS. It just executes a standard `fork()` process with namespace boundaries! 🧠
