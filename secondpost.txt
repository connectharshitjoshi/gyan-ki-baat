☕ Gyaan Ki Baat #2 — Cookies, Storage, SSL & HTTPS 🔍

As a Software Engineer or Web Developer, you deal with these 6 concepts every day... 
But do you know how they actually work under the hood? 🤔👇

Here is a 2-minute breakdown every developer should save:

---

🍪 1. Cookies
Small pieces of data stored by the browser. Sent back to the server with subsequent HTTP requests.
• Best used for: Session management, user authentication, tracking.
• Example: You log in → server sends a session cookie → browser attaches it to future requests.

💾 2. Local Storage
Key-value storage in the browser that persists forever (even after closing the browser).
• Best used for: User UI preferences, theme settings, offline app data.
• Capacity: ~5MB to 10MB per origin.

🗂️ 3. Session Storage
Similar to Local Storage, but data lives ONLY for the lifetime of that specific browser tab.
• Behavior: Close the tab → data is gone instantly 🚪.
• Best used for: One-time form data, single-session state.

---

🔐 4. SSL / TLS Certificate
Establishes trust and enables end-to-end encrypted communication between client and server.
• Verifies server identity and protects data in transit from tampering or eavesdropping.

🌐 5. HTTP (HyperText Transfer Protocol)
Standard client-server communication protocol.
• Risk: Transmits data in plain text (unencrypted).

🔒 6. HTTPS (HTTP + TLS Encryption)
HTTP wrapped inside a secure TLS connection.
• Benefit: Ensures privacy, integrity, and authentication for all request/response data.

---

💡 Gyaan Ki Baat: The Web Security Checklist 🛠️

Don't just check if a page loads over HTTPS. 
Open Chrome DevTools (Application & Network tabs) and verify:

✅ Are sensitive cookies marked `Secure` (HTTPS only)?
✅ Is `HttpOnly` enabled to prevent XSS script access?
✅ Is `SameSite` set correctly (`Lax` / `Strict`) to prevent CSRF?
✅ Are sensitive tokens/passwords kept OUT of Local & Session Storage?
✅ Is the SSL/TLS certificate valid and non-expired?
✅ Do unencrypted `http://` URLs automatically redirect to `https://`?

Remember: Web development isn't just about UI — it's about understanding client-server security! 🔍
