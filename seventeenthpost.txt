Most developers treat SEO like mystical marketing wizardry or keyword stuffing.
In reality, Google Search is a massive, distributed real-time engineering pipeline processing over 8.5 Billion queries per day.

Here is what actually happens under the hood when Googlebot crawls your site — and how you can rank #1 on Google: 🧠👇

1️⃣ Stage 1: Googlebot Web Crawling & The Crawl Budget 🕷️
Googlebot doesn't "see" your site like a human. It's a distributed crawler running millions of concurrent HTTP GET requests.
• URL Frontier: Manages the priority queue of URLs to crawl.
• DNS & robots.txt: Checks your crawl permissions before fetching a single byte.
• XML Sitemap: Tells Googlebot exactly which routes exist without forcing it to discover every link manually.
💡 Rule: If your server responds with >500ms TTFB or 404s, Googlebot slashes your "Crawl Budget" and moves on to another site.

2️⃣ Stage 2: The Two-Wave Rendering Trap (Why Single-Page Apps Fail at SEO) ⚡
Did you build your portfolio in pure client-side React / Angular / Vue?
• Wave 1: Googlebot fetches the raw HTML. If it's just `<div id="root"></div>`, it sees an EMPTY page with zero keywords!
• Wave 2: Googlebot's Web Rendering Service (WRS) spins up a headless Chromium instance to execute your JavaScript bundle.
⚠️ BUT rendering JS consumes 100x more compute than parsing raw HTML. WRS queues client-rendered pages in a rendering queue that can take DAYS or WEEKS to execute!
💡 Fix: Use Static Site Generation (SSG) or Server-Side Rendering (SSR). Pure static HTML (like GitHub Pages) gets indexed instantly in Wave 1!

3️⃣ Stage 3: The Inverted Index (How Bigtable Stores Your Tokens) 📚
Google doesn't search web pages during query time — that would take minutes.
Instead, Google's indexing pipeline parses your HTML into lexical tokens (stemming, lemmatization, stop-word removal) and writes them into an Inverted Index stored in Bigtable:
• Token: "harshit" ➔ [DocID: 104, Position: 1, Tag: <title>, Weight: 0.95]
• Token: "playwright" ➔ [DocID: 104, Position: 24, Tag: <h1>, Weight: 0.88]
Your `<title>`, `<meta name="description">`, and `<h1>` tags carry exponential mathematical weighting in the token matrix.

4️⃣ Stage 4: PageRank & Semantic Ranking (RankBrain & Entity Graphs) 🏆
When someone searches on Google, Google runs:
• PageRank (Link Graph Eigenvector Centrality): External links pointing to your domain act as cryptographic "votes" of trust. Linking your GitHub portfolio to a high-authority LinkedIn profile transfers domain equity!
• RankBrain & Helpful Content AI: Evaluates searcher intent and semantic embeddings, not just exact keyword matches.
• Core Web Vitals (Real-User Metrics): Largest Contentful Paint (LCP < 2.5s), Interaction to Next Paint (INP < 200ms), and Cumulative Layout Shift (CLS < 0.1).
