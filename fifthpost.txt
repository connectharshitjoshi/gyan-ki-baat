☕ Gyaan Ki Baat #5 — Under the Hood: The Browser Rendering Pipeline 🚀

Ever wondered what actually happens between fetching HTML and pixels rendering on your screen at 60 FPS? 🖥️👇

Here is a 2-minute breakdown of the Critical Rendering Path (CRP):

---

1️⃣ HTML → DOM Tree 🌳
The browser parses raw HTML bytes into DOM nodes.

2️⃣ CSS → CSSOM Tree 🎨
CSS rules are parsed into the CSS Object Model tree.

3️⃣ Render Tree 🏗️
DOM + CSSOM combine to form the Render Tree (ignoring `display: none` elements).

4️⃣ Reflow (Layout) vs. Repaint 📏
• Reflow (Expensive): Recalculates width, height, and geometry positions (triggered by `fontSize`, `width`, `top`).
• Repaint (Cheaper): Recalculates visual colors/borders without changing layout.
• GPU Compositing (Best): Using `transform` and `opacity` bypasses Reflow & Repaint, offloading directly to GPU!

---

💡 Gyaan Ki Baat:
Layout Thrashing happens when JS reads geometric props (like `offsetHeight`) inside a loop while changing styles. Always batch reads first, then batch writes! ⚡
